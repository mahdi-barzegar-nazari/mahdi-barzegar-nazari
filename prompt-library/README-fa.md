# راهنمای استفاده از کتابخانهٔ پرامپت

این پوشه شامل پرامپت‌های آماده برای ابزارهای هوش مصنوعی (مانند Claude و ChatGPT) است.
هر فایل `.txt` شامل یک پرامپت کامل است که می‌توانید آن را کپی کرده و در
چت‌بات مورد نظرتان استفاده کنید.

## روش استفاده:
1. فایل پرامپت مورد نظر را باز کنید.
2. کل متن را کپی کنید.
3. در یک گفتگوی جدید با مدل هوش مصنوعی، آن را پیست کرده و گفتگو را شروع کنید.
